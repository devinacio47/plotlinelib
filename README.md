# Plotline Library

A digital library platform dedicated to exploring literary classics.

## Live Application

Visit the live project here: [plotlinelib.com](https://plotlinelib.com)

## Tech Stack

- **Frontend:** React, Next.js, TailwindCSS
- **Backend:** Node.js, Next.js
- **Database:** PostgreSQL, Prisma ORM

## Getting Started

This is a hosted application. You do not need to download or install any local files. Simply open your web browser, navigate to the [live URL](https://plotlinelib.com), and start exploring the digital collection immediately.
